EXPERIMENT NOTES

What changes between the methods?

B

LAM-A2E

The baseline converts speech into facial blendshape coefficients. Its output is rendered on the same avatar used by the enhanced configurations.

P

Prosodic events

Energy, pitch, and their changes locate speech events. Each event drives a fixed brow-raising motion with a rise and a return to rest.

PA

Prosody + action bases

The same event timing drives a combination of Open and Focus. Open raises the brows and opens the eyes; Focus lowers the brows and tightens the eyelids.

Shared speech and rendering

T1–T5 represent calm, excited, questioning, serious, and lively delivery. The Chinese speech was synthesized with edge-tts using the zh-CN-YunxiNeural voice. Within each comparison, every method uses the same audio, avatar, camera, and frame rate.

The upper row presents the face; the lower row enlarges the corresponding brows and eyes. All columns in each video are already synchronized.

Same-avatar model comparison

The five columns show EchoAvatar, EmoTalk, NVIDIA Audio2Face-3D, LAM-A2E, and PA-LAM-A2E. Their animation outputs are rendered on the same avatar.
